Tentang Saya

Saya adalah siswa SMK Negeri 1 Jenangan, jurusan Rekayasa Perangkat Lunak (RPL), dengan minat di bidang pengembangan web — mulai dari sisi tampilan (front-end) hingga logika server (back-end).

Ketertarikan saya pada web development bermula dari rasa penasaran melihat bagaimana sebuah rancangan tampilan bisa berubah menjadi website yang benar-benar bisa dipakai orang. Dari situ saya mulai belajar HTML dan CSS untuk membangun tampilan, lalu merambah ke JavaScript untuk membuat halaman lebih interaktif, dan akhirnya ke PHP serta MySQL supaya website bisa menyimpan dan mengolah data sendiri.

Saat ini saya sedang mengerjakan proyek pembuktian kompetensi Skema Junior Web Developer. Ada dua website yang saya kerjakan: website profil pribadi ini sebagai contoh website statis, dan sebuah website katalog produk rajutan yang dinamis serta terhubung ke database MySQL — mulai dari perancangan struktur data, tampilan halaman, sampai bagian back-end yang mengambil data produk secara otomatis.

Bagi saya, kode yang rapi bukan cuma soal tampilan yang enak dipakai, tapi juga soal menghargai waktu orang lain yang nantinya membaca atau melanjutkan kode tersebut — baik itu developer lain, maupun diri saya sendiri di kemudian hari. Karena itu saya berusaha membiasakan diri menulis kode yang terstruktur, konsisten dalam penamaan, dan tidak berlebihan — cukup ringan dan mudah dipahami.

Ke depannya, saya masih terus belajar, terutama React untuk pengembangan front-end yang lebih modern dan Laravel untuk membangun back-end yang lebih rapi dan terstruktur. Harapannya, ilmu yang saya pelajari sekarang bisa jadi bekal untuk membangun website-website yang lebih kompleks di masa depan.
